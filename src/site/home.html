A minute with Addonova

One tool for the whole extension.

Scaffold, develop, build, validate, and package with the same CLI — click a step, or just watch.

  1. Creates a working extension from a bundled template — background, content script, popup, and config. Docs
  2. Builds, launches a browser with the extension, watches files, and reloads on change. Docs
  3. Produces one loadable extension directory per browser, each with its own manifest. Docs
  4. Checks manifests, locales, and entrypoints against the target's rules before packaging. Docs
  5. Zips the validated output into a deterministic archive ready to upload to a store. Docs
